# WAVE project page

Static project page for *Object Count Generalization Is an Interface Problem: Warping a Frozen
Skill Instead of Retraining It* (WAVE), built on the
[Nerfies](https://github.com/nerfies/nerfies.github.io) template.

    python3 -m http.server 8000     # preview at http://localhost:8000

The scripts expect the paper repository (Overleaf clone) next to this one, at `../wave-iclr-2026`.

| Path | Contents |
|---|---|
| `index.html` | the page; a `TODO` comment marks the author page links still to fill in |
| `static/css/index.css`, `bulma*.css` | Nerfies template styles, unmodified |
| `static/css/wave.css` | additions for the charts, tables, figures and affiliation logos |
| `static/js/charts.js` | interactive success-vs-count charts (hover, legend toggles, tabs) |
| `static/js/data.js` | chart data, generated by `scripts/build_data.py`, do not edit |
| `static/figures/` | architecture diagrams as standalone HTML, embedded as scaled iframes |
| `static/js/figure_notes.js` | hover notes and links on those diagrams; hotspot rectangles are in figure pixels and must be re-measured if a diagram's layout changes |
| `static/images/necessity_episode.png` | copied from `../wave-iclr-2026/figures/` |
| `static/images/logos/` | affiliation logos, each with a dark-mode variant where its lettering is dark; BIFOLD and Robotics Institute Germany taken from their websites |
| `static/paper/wave.pdf` | the paper, built from `../wave-iclr-2026` with the page header "Preprint. Under review." |
| `static/videos/sim/`, `static/videos/real_*` | task and real-robot videos, encoded from `../wave-iclr-2026/wave_videos_submission` by `python3 scripts/encode_videos.py [source dir]` |
| `static/js/warp_viewer.js`, `warp_view3d.js` | the Warp Explorer section: task selector, player, warp bars, 3-D view (three.js) |
| `static/js/warp_data.js`, `static/js/warp_tasks/`, `static/videos/warp/` | its data, one file and three episode videos per task, built by `python3 scripts/build_warp_data.py [recordings dir]` from the renders of the Warp Explorer's `render_warp_3d.py` (3 episodes per task). The renders were made on the VCA cluster and are not kept locally; copy them to `../warp_recordings` before rebuilding |
| `static/js/panda_meshes.js` | Panda link meshes for the 3-D view, built by `scripts/build_panda_meshes.py` from `../rai-robotModels` |
| `scripts/build_data.py` | regenerates `data.js` from `../wave-iclr-2026/figures`: `count_curve_data.csv` for WAVE, the skill alone, the Panda arm and the ablations, and the baseline figures `line_baselines.pdf` / `tower_baselines.pdf` for the other baselines (`scripts/baseline_curves.py`, needs `pdftocairo`), since the CSV holds an older evaluation of them |

After the paper's results change:

    python3 scripts/build_data.py
    cp ../wave-iclr-2026/figures/necessity_episode.png static/images/
